# 🚀 Full Stack Python Developer Roadmap (Django + DSA)

A practical and structured guide for mastering Django development and Data Structures & Algorithms (DSA) in parallel.

---

## 🎯 Why Both?

| Skill | Purpose |
|-------|---------|
| 🛠️ Django | For building powerful web apps and APIs |
| 🧠 DSA | For writing efficient code and acing interviews |

---

## 🗓️ Weekly Learning Strategy (Balanced)

| Day       | Django Focus                      | DSA Focus                             |
|-----------|------------------------------------|----------------------------------------|
| Monday    | Django topic/module                | 1-2 Easy DSA Problems                  |
| Tuesday   | Django models/views/templates      | Arrays or Strings                      |
| Wednesday | Forms / Admin / Authentication     | Stacks or Queues                       |
| Thursday  | Class-Based Views / DRF / API      | HashMap/Set, Sliding Window problems   |
| Friday    | Django ORM / DB / CRUD App         | Sorting & Binary Search                |
| Saturday  | Build a Django mini project        | Solve 3 Medium-level problems          |
| Sunday    | REST API / Deployment Practice     | Recap + Mock Test (DSA)                |
