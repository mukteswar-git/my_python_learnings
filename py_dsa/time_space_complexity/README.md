## Time and Space Complexity

### Time Complexity
*Time Complexity* is a measure of the amount of **time an algorithm takes to run**, relative to the size of the input. 

**Rules: -**
1. Always calculate time complexity in worst case
2. Avoid constant values and lower bounds

### Space Complexity
*Space Complexity* is a measure of the amount of **memory** an algorithm uses relative to the size of the input. It accounts for the memory required by the algorithm during execution, including both temporary space and space used for the input.
